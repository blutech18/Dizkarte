## Core invariants → enforcement

| Invariant                          | Where enforced                                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 1 Auth ≠ authorization             | RLS policies + `SECURITY DEFINER` re-checks                                                                       |
| 2 Gate exact/contact/chat          | table separation, RLS, `isCommunicationUnlocked`, conversation created on confirm; assignment-scoped Admin (0013) |
| 3 One active booking               | `uq_booking_active_per_task` + locked `select_offer`                                                              |
| 4 No self-confirm / tasker release | actor gates + `confirm_completion_and_release` client-only                                                        |
| 5 Derived balances                 | ledger + `derive_user_balances`; no mutable balance column                                                        |
| 6 Idempotency                      | unique keys + `provider_events` replay protection                                                                 |
| 7 Server-controlled + audited      | RPCs + `moderation_actions`/`audit_logs`; provider-authoritative refund/payout finalization (0013)                |
| 8 Short-lived private storage      | private buckets + `MediaSigner` TTL; row-bound object policies + safe path parsing (0013)                         |
| 9 No synthetic in prod             | config guard + `assertSyntheticAllowed` + edge fail-closed                                                        |
| 10 No real data in tests/logs      | synthetic fixtures; structured secret-free logging guidance                                                       |
